用药提醒类 App 最怕的不是丑，而是**该响的时候没响**。[Pill O'Clock](https://github.com/chilin11/Pill-O-Clock) 的目标就三个词：简单、可靠、好看。

## 两个页面，外加一个小组件

- **今日**：打开 App 只回答一个问题：「现在该吃什么药？」顶部大卡片显示下一次服药的药名、剂量和倒计时，一键「已服用 / 跳过」，下面是今天的时间线。
- **药物**：添加药名、剂量、图标、一个或多个服药时间，重复规则可以选每天、工作日、周末或自定义。
- **记录**：近 7 天的坚持率圆环，外加 14 天明细，漏服的可以事后补记。
- **桌面小组件**：4×1 单行，显示「8:00 · 2 小时后」，右边直接点「已服用」。

配色是暖色调：陶土橙、奶油底、墨棕色文字，也支持深色模式。

## 可靠性：这才是重点

### 用精确闹钟，不靠 App 活着

提醒使用 `USE_EXACT_ALARM` 精确闹钟，由系统负责准时触发，不依赖 App 进程是否存活。

### 状态是推导出来的，不写进数据库

这是我最喜欢的一个设计。数据库里**只记录用户的动作**：`TAKEN` 或 `SKIPPED`。「未服用」这个状态从来不存，而是实时推导：

```kotlin
// 伪代码：一剂药的状态由事实推导，而不是存储
val status = when {
    log != null           -> log.action   // TAKEN / SKIPPED
    now > scheduledTime   -> MISSED
    else                  -> UPCOMING
}
```

这样就不存在「状态机跑飞了」「数据库和闹钟对不上」这类问题。

### 闹钟会自己修复

任何数据变化、开机、修改系统时间、更新安装之后，都会**全量重建**所有闹钟。如果某个旧闹钟引用的药物已经被删掉，触发时会先校验，然后静默丢弃。

### 不打扰

- 提前吃了药，到点检测到已经有记录，就不会再提醒；
- 设备关机错过太久的剂量，只在界面上标记「未服用」，不会开机后连响一串通知；
- 点了「已服用 / 跳过」，10 分钟后的稍后提醒会立即取消。

### 自带体检

设置页可以一眼检查三项：通知权限、精确闹钟、电池优化。还内置了「10 秒后发送测试提醒」，随时验证整条提醒链路是否正常。国产 ROM 的后台限制很多，这个功能很实用。

## 自己编译

用 Android Studio 打开项目，或者：

```bash
./gradlew :app:assembleDebug
```

支持 Android 8.0 及以上。首次启动时按提示授予通知权限，然后在桌面长按空白处，添加 Pill O'Clock 小组件。

家里有长辈需要按时吃药的话，不妨试试。欢迎提 Issue 和 PR。
