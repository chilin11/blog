有时候只是想**玩一会儿**：打开网页，点一下，开局。不注册、不加载广告、不弹窗。于是我做了 [little-play-arcade](https://github.com/chilin11/little-play-arcade)，一个可以直接部署的小游戏聚合站。

## 里面有什么

目前收录的游戏分成两类。

**给大人的经典款：**

- **五子棋**：人机对战、本地双人、悔棋。
- **2048**：滑动合并、单步撤销、自动续局，合成 2048 之后还能继续挑战。
- **扫雷**：9 × 9 / 12 × 12 两档棋盘，首次翻开周围必定安全，手机上可以插旗。
- **国际象棋**：合法走子、将军与将死、王车易位、吃过路兵、升变，规则都照顾到了。
- **喵喵星际队**：三轨射击，10 个关卡外加 Boss，支持触屏。

**给 5～8 岁孩子的：**

- **森林邮差**：不需要认数字的路径益智。
- **花园翻翻乐**：记忆配对，三档难度。
- **星星接接乐**：45 秒的温和反应小游戏。
- **魔法衣橱**：分层 SVG 换装，没有倒计时、没有失败惩罚。

## 设计上的几个取舍

### 1. 零后端、零构建

整个站点就是 `public/` 目录下的静态文件。**生产环境不需要 Node.js**，也没有数据库。游戏列表来自一个 `games.json`，分类会根据配置自动生成。

收藏、最近玩过、最高分这些数据都存在浏览器的 `localStorage` 里：不追踪、不上传，代价是不能跨设备同步。我觉得对小游戏来说，这个取舍很划算。

### 2. 不向外发请求

封面和图标都是本地 SVG，没有 CDN、远程字体，也没有统计脚本。打开页面时，浏览器只会和你自己的服务器通信。

### 3. 每个游戏都有独立链接

游玩页按需加载 iframe，每个游戏都能单独分享：

```text
/play.html?game=gomoku
```

还带全屏、在新窗口打开、确认后重载和操作说明。

## 三种部署方式，总有一种适合你

**本地预览**（Node.js 20+，无需 `npm install`）：

```sh
PORT=5180 npm run dev
```

**VPS + Docker + Caddy**，自动申请 HTTPS 证书：

```sh
git clone https://github.com/chilin11/little-play-arcade.git ~/little-play
cd ~/little-play
cp .env.example .env   # 在里面填 SITE_ADDRESS=你的域名
docker compose up -d --build
```

**最小的 VPS**：连 Docker 都不想装？仓库里带了一个 systemd 服务，只依赖 Python 3 标准库，直接监听 5180 端口。

> 小提示：直接双击 `index.html` 是跑不起来的，因为大厅需要通过 `fetch` 读取 `games.json`，必须用 HTTP 服务器打开。
